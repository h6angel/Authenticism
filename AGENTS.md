# Repository Language

Use English for all tracked project content, including documentation, skill instructions, comments, example prompts, and published evaluation records. This is a repository convention, not a restriction on the language used when the installed skill answers users.

New evaluation runs should use English prompts and save temporary output under the Git-ignored `evaluations/local-runs/<run-name>/` directory. Publish only selected evidence under `evaluations/results/`. If historical non-English records are translated for publication, identify them as translations and preserve the distinction between original execution and editorial translation; do not present translated output as a new run or reuse old readability scores as scores of the translation.
